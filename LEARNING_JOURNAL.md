Semaine 1 : Prise en main de Python et de l'environnement

1. Ce que j'ai appris

Cette première semaine a été consacrée à la découverte de Python et à la prise en main de Google Colab, mon environnement de travail pour le projet SmartMessage AI.

J'ai travaillé sur les notions fondamentales de Python :

- Les variables et les types de données.
- Les conditions "if", "elif" et "else".
- Les boucles "for" et "while".
- Les fonctions simples.
- Les chaînes de caractères et leur manipulation.
- La lecture et la compréhension des erreurs Python.

J'ai également commencé à comprendre comment ces notions peuvent être utilisées pour manipuler des messages textuels, qui constitueront les données de mon futur système de classification HAM/SPAM.

2. Ce que j'ai développé

J'ai réalisé des exercices pratiques dans Google Colab afin d'appliquer les notions étudiées.

Mon travail a notamment porté sur :

- La création de variables contenant des messages.
- L'écriture d'une fonction permettant de calculer la longueur d'un message.
- Le comptage des mots dans une phrase.
- La création et le parcours d'une liste de messages.
- La détection et la correction d'erreurs Python.

Ces exercices m'ont permis de commencer à utiliser Python pour manipuler du texte de manière simple.
