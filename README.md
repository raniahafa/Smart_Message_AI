# SmartMessage AI

### Projet de détection de messages indésirables (Spam)

## Présentation

SmartMessage AI est un projet d'apprentissage en intelligence artificielle dont l'objectif est de développer un système capable de distinguer les messages indésirables (Spam) des messages normaux.

Le projet est réalisé progressivement, à travers des exercices pratiques et l'apprentissage des outils nécessaires à sa réalisation.

## Objectifs

- Apprendre et pratiquer Python.
- Découvrir la manipulation des données avec Pandas.
- Explorer et nettoyer un jeu de données au format CSV.
- Préparer les données pour la détection de spam.

## Technologies utilisées

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
